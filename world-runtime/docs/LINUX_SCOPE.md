# Linux实施切片（2026-10-04用户明确调整）

授权：用户在研究交付后明确要求“完成成品，先把Linux端跑通”。本轮不能因Android/macOS/Windows缺实测停止Linux实现，亦不把这些平台标通过。继续已有DSH Tavern固定源码，在world-runtime应用模块添加独立WorldMode入口；旧Tavern模式保持原样，不启动其默认宽权限工具profile。

## 本轮必须可演示的产品
- Linux本地浏览器真实UI（非CLI替身），导入ST JSON/PNG与Risu CharX/素材，保留原件和未知能力逐项报告
- 正文草稿→单库正式正文/状态/outbox共同提交→真实DSH Session持久投影；取消、重试、重启与失败恢复不重复状态
- 人物、单值地点、多值有向关系、事实/认知/目标、变量/物品、事件/证据；玩家/作者视图明确
- 分支从历史提交建立，分支隔离；基于分支正史构建稳定模型上下文，不把秘密/未来计划当公开正史
- 原生声明式交互与变量，未知JS/Lua不执行、不宣称完整旧插件兼容
- 有界日程推进与自主模式，默认关闭；零到期事项不调用模型，预算/停止/恢复可见
- 单一OpenAI-compatible协议；无key本地演示清楚标识，不伪称真实AI；服务端环境变量配置真实endpoint/model/key，测试不发起付费请求
- 一致性备份、在新目录恢复、导出可读剧情；完整源码/锁/启动说明与自动化/真实浏览器E2E

## 技术边界
DSH原生Session/JSONL被最小boot复用为宿主投影；world-runtime不是全量Tavern前端重写，不改旧默认finalize，而是新WorldMode独立入口，由本模块独占世界字段。底层Node24.19 SQLite先接受为Linux切片驱动；其他平台仍待验证。无微服务、第二套Harness、云账号、任意脚本执行、自动外部资源下载或外部发布。HTML始终文本/安全静态素材，不执行卡片HTML脚本。

每项功能需要测试与UI实测。原型通过不自动转为生产通过；参考同一故障与版本门。最终独立审核先聚焦新增/前问题再通读完整实现，Spec与Quality无Major才可通过此Linux切片。
