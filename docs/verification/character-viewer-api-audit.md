# 命定之诗悬浮角色库接口核验

日期：2026-09-10。范围：CharInfo-Manager v0.2.4，当前 DSH Tavern。

## 已取得的证据

- 真实浏览器打开世界书角色库，读取当前人物卡名称、绑定世界书和 29 个角色。
- 在界面启用埃尔薇拉；聊天持久化日志 revision 39 将 entries[306].enabled 写为 true。整页刷新后重新打开，仍显示已启用。随后通过界面恢复禁用，revision 41 确认 false。
- 此对话已带 openingWorldbookSnapshot，正式宿主将修改写入聊天存储。人物卡源文件未变化不是保存失败。本次没有修改该存储策略。
- 真实视觉编辑器可选择世界书及角色，读取角色资料，进入主题、相册和确认写入前的步骤。没有保存测试视觉内容到用户的角色条目。
- 34 项相关测试通过，涵盖真实宿主及文件世界书增删改、重新连接回读、未知字段保留、并发覆盖拒绝、消息变量写入/失败回退和脚本变量作用域。
- 新增聊天快照场景测试，验证 enabled 和 content 经过正式宿主写入聊天持久化边界，重新连接后可读，源人物卡不受影响。该测试不等于视觉编辑器完整 UI 保存验证。

## 确认的缺口

独立扩展图库路径会在图库书不存在时调用 createWorldbook，然后通过 getWorldbook、createWorldbookEntries、updateWorldbookWith 写入另一份世界书。当前未暴露 createWorldbook，宿主还明确限制只能访问当前绑定的世界书。因此勾选“使用独立扩展图库”不能视为兼容。仅补一个同名函数不足以解决其存储与访问范围问题。

## 尚未完成的界面验证

- 普通视觉资料实际保存、重新打开后的解析。
- 脚本查看器设置和悬浮球位置跨刷新保存。
- 扩展图库创建、写入失败后的恢复。

建议单独设计扩展图库存储边界，避免为素材库无意放开全部世界书。当前不能声称所有底层接口已完整兼容。
