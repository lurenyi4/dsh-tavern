# 动态常驻世界书

常驻表示启用后每次请求都提供，不表示内容永远不变。DLC 开关、EJS 和宏变量都可能改变常驻内容。

请求装配采用当前世界书的启用状态，按既有 Tavern 顺序解析常驻条目。EJS 使用当前游戏变量；普通宏在本次解析中共享状态，条件条目的正文投影继承这一临时宏状态，不回写游戏变量。

常驻结果放在系统区块前部，替换开局快照中的常驻部分。人物卡固定背景继续复用。这里只改变模型请求投影，不修改 Session 历史，也不追加世界书修订消息。空结果会移除旧常驻区块。前台不再把常驻 EJS 结果重复放入正文 Frame；后台在任务开始时捕获当前结果，任务内保持一致。

结果不变时，维持相同顺序与格式；结果变化时接受后续前缀缓存失效，优先保证当前设定正确。未启用条目仍可按原有模板机制被 getwi 显式引用，不会自行激活。

验证覆盖开关往返、EJS 值变化、常驻 setvar 与条件 getvar、系统区块替换、前台不重复注入，以及持久后台会话的下一任务更新。实卡验证使用本机命定之诗 v4.3.1 中的史莱姆用途和骸响之都补充条目；不等同于完整 Windows 存档端到端验证。
