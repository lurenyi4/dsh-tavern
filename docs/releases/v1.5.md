# v1.5 发布记录

发布日期：2026-09-07。以下为 v1.4 以来的主要变更。

v1.5 主要围绕“把酒馆里的故事接着玩”展开：新增聊天记录导入和剧情分叉，补齐复杂人物卡的开场交互，允许按需关闭后台工作，并修复回退、重新生成、上下文压缩和状态栏显示中的一批实际问题。

## 新增聊天记录导入

- 先选择与聊天记录匹配的人物卡，再在游戏准备页点击“导入聊天记录”，把 SillyTavern 导出的 JSONL 对话导入为一局新的 DSH Tavern 游戏。
- 导入会结合绑定人物卡、世界书和开局预设，为历史轮次补齐 DSH 的任务说明与上下文，恢复逐轮输入、回复和状态关联，可以从已有剧情继续游玩。
- 支持恢复文件中可识别的 MVU 变量快照。缺失状态时沿用最近有效快照或人物卡初值，并提示恢复情况；不会根据正文猜出历史变量。结构不兼容时可改选人物卡，或选择仅导入正文。
- 导入后的对话沿用原生机制：最近 40 个回退点、最后一轮重新生成，以及从当前进度分叉。后台从导入后的进度开始工作，不重复结算整段历史。
- 对远超所选模型上下文容量的导入记录，首次续玩会保留开头必需内容和最近完整轮次，按模型容量预留余量、以约 80% 为整理目标，让中间旧轮次退出当前模型上下文。原始记录保留，可通过历史检索找回；后续继续使用原生压缩机制。
- “导入聊天记录”与“开始新游戏”分开放置，并提示聊天记录必须与人物卡匹配。

当前导入以单人对话正文及可识别的 MVU 快照为主，不恢复未选中的其他回复、插件数据库或原酒馆的完整运行环境。文件上限为 8 MB、2000 条源消息；暂不支持群聊和依赖附件的消息。

## 新增剧情分叉，修复回退与重新生成

- 可以从当前进度建立独立分支，尝试另一条剧情路线；原对话保留不变。
- 分叉继承当前有效的正文和状态，正确保留此前回退、重新生成后的结果，避免把已经弃用的剧情带回新分支。
- 修复连续回退、中止重新生成后遗留空轮次，以及结算失败后无法回退等问题。
- 重新生成时，模型请求也会排除被替换的旧正文；修复只更新界面、模型仍看到旧内容的问题。
- 修复后台结算结果归错轮次的问题，避免回退或重新生成后，迟到结果覆盖当前状态。

## 后台任务可以单独开关

在“设置 → DSH Tavern → 后台结算”中，新增三个独立开关，默认全部开启：

- **变量结算**：更新 MVU 变量和状态栏，普通卡不执行此项。MVU 卡强烈建议保持开启，否则正文推进后，变量可能仍停在旧状态。
- **人物姿势结算**：总结人物当前的位置、动作和姿势。
- **人物设计档案**：按需补充人物档案。NPC 较多时，可关闭这项来减少不需要的生成和等待；候选生成也遵守此设置。

开关对后续派发的任务生效，已经运行的任务完成本轮，已有档案与状态保留。重新开启变量结算只处理后续轮次，不补算已跳过的历史。关闭的工作不再派发，但不因切换开关反复改写后台固定工具目录。

同时调整了正文与后台结算的关系：正文生成成功就先保存。后台结算失败不再撤销成功正文，也不会锁死下一轮；可重试最新轮次的结算，过期结果不会覆盖新剧情。

## 补齐人物卡开场与脚本交互

- 游戏开始前可以预览开场，只有一条开场白的人物卡也会进入准备页。
- 支持更多由 HTML、视频、音乐和人物选择组成的交互式首页；脚本的开场选择接入 DSH 原生建局流程。
- 准备阶段拥有独立草稿，人物卡首页对世界书条目和开场的调整保存到本局，避免影响其他游戏或共享资源。
- 补充酒馆助手、SillyTavern 宿主对象、世界书读写、开场保存与重载等常用接口，将这些操作接入 DSH 的会话和状态机制。
- 补充脚本提示词注入与撤销：相关内容可参与世界书触发，并进入本轮 Frame，与 MVU 结算和回退保持关联。
- 修复脚本显示依赖缺失，以及远程资源无法解析 Git 引用时，实际可用的 CDN 内容也被禁用的问题。
- 修复较大视频被整文件缓存限制挡住的问题，音视频改用流式加载。

本轮实际修复涉及：

- **《岁岁年年》**：交互首页被过滤、视频无法显示、人物开场选择无法衔接。
- **《命定之诗》**：仅显示“首页”、环境检查与世界书选项无法读取、MVU 所需提示词注入缺失，以及“开始旅程”无法衔接等问题。
- **《道渊》**：开场内容被截断，无法滚动到开始入口，以及开场切换无法衔接的问题。
- **《染魔》**：状态栏中 `{{user}}` 等玩家、角色宏没有展开的问题。

这些是具体版本、接口和使用路径的适配修复，不代表完整实现了 SillyTavern、酒馆助手或 EJS 插件的全部功能。

## 正文、状态栏与界面修复

- 混合消息中的小说正文与 HTML 界面分开渲染，不再因为一段状态栏 HTML 就把整篇正文塞进 iframe；补齐 `gametxt` 正文标记的识别。
- 修复折叠内容仍被计入 iframe 高度，导致状态栏移到右侧后正文下方留下大片空白的问题。
- 修复字号大于 14 时，状态栏交互和 CSS 动画可能反复放大文字的问题，避免字号缩放累加。
- 玩家和角色宏也会在显示模板中展开，不再直接显示 `{{user}}`、`{{char}}`。
- 隐藏用于模型上下文的预置助手回复，普通会话和分叉都不再把“明白，后续我会……”显示成剧情正文。
- 人物卡库支持显示 PNG 卡片封面，游玩历史按最近打开排序，场景插图预览适应可用宽度。
- 修复候选项已经生成却要等刷新才出现、Tavern 通知丢失，以及 Session 信号传递中快照没有正确保留的问题。

## 预设编辑更清楚，开局配置固定

- 预设编辑器分为前、中、后三段，并说明每一段如何进入模型请求：前段放在系统提示词开头，中段加入每轮任务说明，后段放在本轮请求末尾。
- 每局游戏固定使用创建时的预设快照。之后切换预设、修改提示词或预设正则，不会影响已经开始的游戏；要使用修改后的配置，需要新开一局。
- 重写预设库说明，明确 DSH 与酒馆的运行方式不同，同一份预设不保证产生相同效果；后台 Agent 不运行游玩预设。

## 上下文压缩与模型兼容修复

- 修复前后台压缩出现 `assistant/message ... has no matching step/start event` 的报错，补齐原生 Token Meter 对 Tavern 预置助手消息和历史替换的计量适配，保留原始 Session 事件。
- 人物卡、常驻世界书和开局固定偏好进入前后台原生固定系统上下文，不再作为聊天正文参与压缩。旧会话自动迁移；压缩、重开和分叉后仍保留开局背景。
- 简化前台压缩提示词，主要概括人物形象、性格、关系与重要剧情，不再要求逐项保留所有细节；细节仍可通过 recall 检索。
- 系统提示词库中明确列出“前台上下文压缩”，便于查看和调整。后台继续使用 DSH 原生压缩提示词。
- 修复 DeepSeek 对旧思考记录、合成开场和预置助手上下文的续传兼容问题。

## 安装与更新

- 修复 Desktop 更新进程找错宿主依赖位置的问题，继续沿用当前 Desktop 的依赖来源。
- 固定安装器使用的 pnpm 工具链版本，减少环境变化造成的安装差异。
- 清理受信任人物卡脚本留下的宿主临时文件。

## 升级提示

- 更新后重启 Tavern，并刷新浏览器页面，加载新的后端、前端和脚本依赖。
- 后台三个任务默认开启，已有手动配置保留；想减少后台工作量，可先关闭人物设计或姿势结算。
- 导入聊天记录前先确认人物卡匹配；仅有聊天正文时，无法保证恢复当时的全部变量状态。
- 旧会话迁入固定系统上下文后，首次请求的缓存前缀可能变化，之后按固定背景继续复用。
- 已经自定义过前台压缩提示词的用户，原设置不会被覆盖；想采用本版简化提示词，可在系统提示词库恢复默认。
