# v1.6 发布记录

发布日期：2026-09-09。以下为 v1.5 以来的主要变更。

v1.6 主要改善日常游玩与管理体验：支持批量删除对话、多选导入人物卡和直接编辑正文；修复回退后后台重复创建、正文分段丢失、状态栏字号异常等问题，并补充文风引导、安装修复和诊断日志。

## 对话和人物卡管理

- 对话历史标题右侧新增“管理”入口，支持多选、全选当前列表和一次确认删除。游玩与卡片工作台分别管理，失败项保留勾选，方便重试。
- 删除前停止相关任务；删除当前对话后切换到剩余对话。删除对话不会删除人物卡和世界书。
- 人物卡库的导入文件框支持多选 PNG、JSON 文件，显示进度和成功、失败数量。单张卡失败不影响其他卡，错误标明文件名；批量导入后留在库中查看结果。
- 安卓下载目录入口仍可逐张导入，也可通过“使用系统文件选择器”选择多个文件，具体以系统选择器支持为准。
- 预设列表增加明确的“打开预设”按钮。

## 直接编辑最后一轮正文

- 新增最后一轮正文编辑，适合修正措辞、错字和局部描写，无需整轮重新生成。
- 保存后同步更新显示与模型后续使用的正文；保留原始历史记录。
- 编辑不重新执行后台结算或脚本，不自动重算变量。若修改改变了剧情事实，需要另行核对状态。
- HTML 界面、脚本和协议外壳保持原样，只开放可编辑的正文部分。生成或后台处理期间暂不可编辑。

## 回退、重新生成与后台复用

- 回退不再因某条历史任务仍标记“运行中”而一直被拒绝。前台正在生成时先停止，再执行正文回退。
- 正文与后台分别恢复。后台历史快照不可用时允许正文先回退，并给出提示；旧任务的迟到结果不能覆盖回退后的剧情。
- 回退后立即尝试恢复后台上下文；后台会话未加载时先恢复会话，再回退并保存。等待后台停止有上限，失败保留后续重试机会。
- 后台对话页面同步隐藏已撤回轮次的思考和工具调用，原始日志仍保留用于排查。
- 修复导入聊天记录后，回退或重新生成把已有后台 ID 清空、导致不断新建子代理的问题。缺少历史边界时，在原后台会话内清理旧任务上下文，保留固定背景。
- 修复后台首次任务开始前未及时保存会话身份的问题，并改善子代理列表刷新和异步错误归属。

此前已经产生的历史子代理记录不会自动删除。后台状态与正文未必严格同步，回退后仍应核对关键变量。

## 文风引导与用户画像

- 右侧状态面板底部新增“想调整文风？”引导，集中提供不同调整方式的入口。
- 用户画像中的偏好维度和原始回答改为展开后才渲染，减少打开面板时创建的节点。
- 合并重复的画像刷新请求，相同数据不再重复更新内容；避免旧刷新结果覆盖新修改或在面板关闭后继续更新。

这些改动减少了画像面板的渲染和刷新开销，但尚不能确认解决了所有设备上“打开面板后整机卡顿”的反馈。

## 正文和状态栏显示

- 修复生成过程中分段正常、结束后正文挤成一块的问题：`<thinking>`、`<content>`、`<gametxt>` 等裸协议标记按叙事文本处理，不再误触发 HTML 页面渲染。
- 独立写作注释不再创建空 iframe；真正的 HTML 美化界面、脚本和样式继续隔离渲染。
- 调整正文字号时，右侧状态栏保持自身字号，避免随正文放大后挤掉线索、破坏排版。
- 修复侧面板被宿主滚动容器裁出可视区域、顶部无法滚回的问题。
- 优化聊天历史的日志重放，避免每处理一条记录都复制整个聊天对象。

## 卡片 Agent

- 卡片 Agent 常开联网搜索能力，方便查找资料和处理资源。
- 修改人物卡的起始任务采用与前台一致的系统上下文和预置消息，再以用户消息注入工作区说明与任务要求。
- 工作区说明通过消息注入，不再整段占据用户输入框。
- 支持在设置中编辑可选的卡片工作台系统指令，默认留空。
- 修复卡片对话气泡缺少显示外壳的问题，恢复显示时保留原始回复。

## 交互人物卡与模板支持

- 补充提示词模板浏览器运行时，接入原生变量存储和资源路由；全局变量保存增加冲突检查，并修复模板就绪状态和历史切片问题。
- 修复前台世界书模板回调参数不匹配的问题，感谢 PR #13 的贡献。
- 开场准备阶段加载已启用的人物卡脚本，改善 MVU 初始化等待、事件处理顺序和跨脚本等待范围。
- 补齐交互首页创建聊天消息、旧式发送控件和独立生成请求的衔接；修复 `/send … | /trigger` 管道分隔符后带空格时无法继续执行的问题。
- 补充脚本环境检测所需的版本、消息框身份及资源接口。

以上是具体接口和运行路径的适配，不代表完整实现 SillyTavern 及其全部扩展功能。

## 模型与联网设置

- 新游戏未手动指定后台模型时，后台跟随当前前台模型，前台切换模型后，后续后台任务跟随使用。
- 已手动指定后台模型的游戏继续使用开局配置；旧游戏已有的固定模型不会自动改成跟随。
- 游玩模式联网开关明确标注“仅新游戏”，避免误以为切换后会立即改变当前游戏。卡片 Agent 的常开搜索与此开关分别处理。

## 安装、更新与诊断

- 修复 Windows 中文路径、带空格路径、后台启动输出重定向和服务状态判断；通过实际 Node 入口启动服务，减少额外控制台窗口。
- 安装依赖默认使用 npmmirror，保留自定义源的配置方式。
- 安卓安装器固定并传递匹配的 pnpm，避免与 DSHA 系统命令冲突。
- 修复安卓入口可能读取旧启动地址的问题；补充点击工作台无反应时，复制完整地址到浏览器打开的说明。此项不代表所有设备的点击问题均已解决。
- 更新程序增加持久诊断记录，包含请求阶段、耗时、错误原因、版本和环境信息，并纳入日志导出。
- 导出日志补充人物卡页面错误、控制台和网络信息，以及经过脱敏的宿主 API 调用记录，便于定位群友反馈。
- 文档补充世界书合并、每卡玩家人设与长期用户画像的区别。

## 升级提示

- 更新后重启 Tavern，并刷新浏览器，确保后端逻辑与前端显示同时更新。
- 后台复用修复适用于旧对话后续的回退和重新生成，不会自动清理历史子代理。
- 若希望使用“后台模型跟随前台”，请在没有手动指定后台模型的情况下新开游戏；旧游戏保留已有配置。
- 游玩联网设置和用户画像偏好仍按新游戏创建时的配置生效。仅关闭用户画像面板不会移除当前游戏的固定偏好。
